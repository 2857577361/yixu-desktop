# 一序 · Windows 版

适用：Windows 10 / 11，64 位 Intel / AMD 电脑。

## 打开

先把 ZIP **全部解压**到长期保留的文件夹（例如 D:\Apps\Yixu），然后双击「一序.exe」。不能只把 exe 单独取出来。第一次打开会创建开始菜单入口；之后也可从开始菜单打开。当前为未购买商业签名证书的版本，Windows 可能显示发行者未验证。请确认文件来自你自己的发布包后再运行。

关闭主窗口后仍在系统托盘运行，可继续提醒。从托盘菜单「退出一序」才完全退出。

快捷键：Ctrl+K 全局查找；Ctrl+Shift+Space 全局快速便笺。快捷键被占用时可从托盘打开快速便笺。

## 功能与数据

与 macOS 共用同一套源码和数据结构：周计划、固定作息、生活月历、习惯、独立打卡、专注、日记、便笺、笔记、稍后学习、PDF/EPUB 阅读、记录、回顾、归档，以及休息小游戏。塔罗随想支持 78 张牌、一牌/三牌、正逆位、翻牌、感想与存入日记。

本机数据保存在 `%APPDATA%\Yixu`。移动应用文件夹不影响记录；请勿删除数据目录。

从 Mac 迁移：在 Mac 设置中「把全部记录带走」导出归档，**完整复制整个归档文件夹**到 Windows；在 Windows 设置中导入其中的完整 JSON。图片和书籍目录需要和 JSON 一起保留。导入前会自动备份 Windows 原记录。

语雀、云同步及 AI 的凭据不在归档内，需重新授权。网页登录状态也不会跨电脑迁移。塔罗本机抽牌历史保存在当前设备，不并入云同步；想保留到跨设备记录，可手动存入日记。

## 手机局域网同步与提醒

在 Windows 设置里打开局域网同步，并按页面提示在手机配对。两端需连接同一个可信局域网；若 Windows 防火墙询问网络权限，允许你自己的专用网络即可。IP 地址以 Windows 设置页显示为准，不能沿用 Mac 的 IP。

提醒依赖应用正在运行，系统设置需允许一序发送通知；睡眠或完全退出时不能即时提醒。点击提醒可处理对应打卡/进入相关页面；系统通知按钮的展示因 Windows 版本而异，应用内提醒操作保持一致。

## 更新与回退

退出旧版本，再把新版本解压到新的文件夹运行。保留旧文件夹和更新前的完整归档，即可重新打开旧版并按需恢复归档。不要同时运行两个版本。

这是从 macOS 交叉打包的 Windows x64 版本；交付前已做源码和包结构检查，仍需 Windows 真机验证通知、防火墙、开机启动和网页视频等系统集成行为。
