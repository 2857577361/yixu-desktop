# 一序共用界面组件

代码：`ui/components.js`、`ui/components.css`。通过 `UIComponents.enhance(root)` 接入；动态弹窗和页面内容由观察器自动接入。

- **选择框**：原始 select 保留，作为表单与事件的数据源；可见按钮采用 combobox，选项采用 listbox/option，支持方向键、Enter、Esc 与焦点回归。多选与列表选择继续采用原生控件。
- **时间 / 日期**：保留原生输入、键盘输入和系统日历；统一 42px 控件高度、留白、边框与数字排版。固定作息、提醒、重复日期、阅读筛选等继续使用原本数据契约。
- **日 / 周 / 周期切换**：统一工具栏按钮、日期和下拉控件的对齐、间距、焦点反馈。
- **关闭按钮**：统一 40 × 40px 点击区域和无障碍名称；原生弹窗支持 Esc 以及点击外部遮罩关闭。按下和抬起都位于遮罩才关闭，避免拖动选择文字时误关。
- **内容不清空**：关闭弹窗仍遵循原页面保存规则；已有草稿机制继续生效。

已检查的桌面页面：今天、周计划、固定作息、生活月历、打卡、稍后学习、阅读、习惯方法、习惯、日记、我的笔记、便笺、记录、回顾、休息一下、设置。阅读器及 AI 助手的动态关闭控件也自动接入。

## 连续记录

`shared/habit-streaks.cjs` 为桌面和服务端共用的自然日算法。done、minimum（含最低版次数）保持连续；主动休息日不计入也不打断；过去未记录和明确跳过会中断；今天尚未记录不提前中断。每周目标的进度保持独立。

里程碑按「习惯 ID + 7 / 21 / 66」唯一保存到 `habitAchievements`，保存日期与确认庆祝时间；已获得记录不会因后来删除行动记录而消失。前端庆祝前原子确认，避免多个窗口重复庆祝。历史补记也参与计算。

## 快速捕获

macOS 菜单栏「快速记便笺」和 ⌘⇧Space 共用 `quickCapture()`。窗口默认 420 × 520，置顶，复用已打开的捕获窗口。支持标题、文字与图片；保存前不创建空便笺；草稿与首页随手一句分开存储。⌘Enter 保存，Esc 关闭并保留草稿。快捷键占用情况可在设置页查看。
