# 一序手机版 0.3：随身记录与局域网同步

## 定位与入口

手机用于查看安排、随手记录和修改，回到电脑继续处理。底部只有五个入口：

- **记录**：按日期写日记、添加图片，自动保存；便笺支持标题、折叠、标题搜索、编辑与删除。
- **周计划**：按天查看工作、学习、读书、运动、备忘，新增与编辑表格安排；整体任务可以修改、安排到当天、记录次数，完成进度与电脑联动。生活月历保留在次级切换入口。
- **打卡**：直接增加或撤销一次，编辑目标次数、多时段提醒、前后置动作；每日达到目标才算一个完成项目。
- **习惯**：查看连续与最长记录、周目标；完成、最低版、跳过、写收获、补记分钟，编辑和删除。只改名称时保留电脑已有的复杂重复规则。
- **我的**：电脑配对、连接状态、冲突处理、备份。原云连接能力收在“其他连接与备份”。

原有数据保留，不会把习惯和打卡合为一套，也不会把电脑正在运行的专注计时器带到手机。

## 首次连接

1. 安装安卓 APK，电脑打开桌面版 0.26.0。
2. 两端连接同一局域网。电脑：设置与连接 → 手机 · 局域网自动同步 → 配对手机。
3. 手机：我的 → 寻找同一 Wi-Fi 的电脑，选择电脑地址，输入电脑显示的 8 位配对码。配对码五分钟有效，一次使用。
4. 如果自动发现失败，填写电脑设置里显示的 `http://内网地址:47931` 即可。

配对后手机在前台每五秒检查一次，回到手机应用时也会检查。电脑一序需要运行，可以在后台；退出、睡眠或断网时手机继续保存本机记录，重新连接后补传。电脑重启后会恢复已启用的同步服务。电脑内网地址变化时安卓通过 mDNS 再发现同一台已配对电脑。

无需额外数据库、云服务器或 Supabase 登录。只在自己的可信局域网使用；访客网络的设备隔离、电脑防火墙可能阻止连接，需允许一序接受局域网连接。局域网传输使用 HTTP 和设备令牌授权，未增加 TLS。

## 数据与冲突

- 通过原有共享同步白名单双向交换周计划、打卡、习惯、日记、便笺及已有的学习、生活事项与记录，保持旧版本数据兼容。
- 日记与便笺引用的本地图片按内容哈希传输，不重复上传；支持 15 MB 以内的图片。手机添加图片会缩小到最长边 1600 像素。
- 语雀凭据、云登录令牌、服务密钥、书籍文件、阅读时间和桌面计时器不交换。配对令牌在安卓 Keystore 加密保存，电脑只保存令牌哈希；不在导出归档中出现。
- 同一条文字记录两端都改变时不静默覆盖，在手机“我的”显示双方版本，选择保留手机或采用电脑。
- 同一打卡的次数按两端增减合并，最多到当日目标。每批操作有独立 ID，超时重试不会再加一次。
- 手机局域网同步独立保存基线，不消费原有云同步队列。配对后优先走局域网。
- 安卓系统后台不保证联网，因此这版明确只在手机前台自动同步，不宣称后台实时同步。

## 验证与产物

桌面 0.26.0、安卓 0.3.0（versionCode 4），沿用应用标识 `local.yixu.mobile`，可以覆盖安装同签名旧 APK，保留本机数据。

- `npm test`：包括局域网双向增删、计数合并、重复重试、并发输入、冲突选择、200 条分批、日期类型、周计划不反复写回、整周删除和图片校验。
- `npm run test:mobile`：浏览器连接真实隔离桌面核心验证自动补传，检查 320 / 390 / 430 / 768 像素的五个页面。
- `YIXU_TEST_EXECUTABLE=/新版.app/Contents/MacOS/一序 node test/lan-desktop-ui.spec.cjs`：实际 Electron 配对、接收手机便笺、撤销授权、关闭同步、页面宽度验证。
- `npm run android:sync --prefix mobile`，Android Gradle `assembleDebug`：构建 APK。

当前没有连接真实安卓手机。Keystore、安卓 NSD 发现和不同路由器下的连接需要拿到手机后做实机验证；浏览器端双向数据链路与 Android 原生编译已经验证。桌面安装前保留 0.25.1 应用及本机数据备份。
