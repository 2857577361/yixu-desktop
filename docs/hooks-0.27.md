# 记录里的近期待办（桌面 0.27 / 安卓 0.4）

在记录正文中输入 `/hook`，会出现一个小输入框。写下准备做的事情，按 Enter，原位置变成带勾选框的小待办；指令不会成为正文。Esc、取消或点输入框外面取消创建。双击原文里的待办文字可以改标题；在原文中用 Backspace 删除待办标记并保存，就会从汇总里移除。

周计划增加独立的“近期待办”，位于整体计划下方。它不属于当前周，切换周不会清空。列表显示待办文字、来源和创建日期，可搜索；已完成默认折叠。勾选只改变待办状态，不改变习惯、专注时长、打卡次数或周计划任务的完成数字。

点击列表里的待办文字会打开原记录的编辑位置，展开所在区域，滚动到对应标记并短暂高亮。日记到指定日期；便笺、笔记、专注和读书笔记到具体原记录，读书笔记保留书籍与页码。相同标题的多个待办用独立 ID 定位。正在编辑其他未保存记录时，会提示先保存，避免丢失修改。

## 支持范围

桌面：日记、便笺（含置顶小窗口和快速捕获）、我的笔记、稍后学习正文/总结/复盘、习惯收获、专注收获、历史记录编辑、阅读笔记，以及周复盘的正文。

手机：日记、便笺、习惯收获、原记录编辑框使用相同的指令与格式。周计划有同源的近期待办，电脑同步来的专注等记录也可以打开对应原文字段编辑。手机仍不下载书籍与阅读统计。

新待办在原记录保存后进入汇总。桌面仍沿用原有“草稿 → 保存”，手机日记沿用自动保存。待办跟随来源文字走现有局域网/云同步，不依赖新的服务；局域网网络不可达的问题与本功能无关。

## 数据与兼容

待办直接保存为正文里的专用 Markdown 链接，包含随机锚点、状态、创建日期，来源与正文只维护一份。读取时动态汇总，不维护另一个容易过时的任务副本。钩子前后增删文字、修改标题、便笺重排不改变锚点。

匹配的习惯和专注只展示一次，切换状态同时更新已关联的两份原文字段。删除来源后不留下孤立待办。手机通用原文编辑有并发校验，拒绝覆盖已经更新的原文。

JSON 备份保留锚点，可以恢复；可读 Markdown、图文 HTML 和语雀正文输出为“☐ / ☑ 待办文字”，隐藏内部链接。旧应用不认识此格式时可能显示 Markdown，因此编辑前建议更新到这一版。

## 验证

- 核心：多来源汇总、同名独立待办、跨周、前文编辑、删除、重复设定幂等、来源重排、习惯/专注合并、既有同步往返、导出、并发保护、旧时间戳。
- 桌面真实 Electron：日记、便笺、笔记、专注弹窗和读书笔记创建，修改标题，勾选与撤销，原位置跳转、高亮，Esc 取消，键盘删除。
- 手机浏览器：创建、自动保存、完成同步、日记/专注原文跳转与编辑，窄屏适配；现有局域网双向补传流程回归。
- Android 编译构建；未连接真实安卓手机，不宣称已经实机验证。
