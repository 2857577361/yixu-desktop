# 0.27.1 小问题修复

- `/hook` 改为检测光标前完整文本，支持紧接中文、跨文本节点、输入法提交后触发；不再依赖空格或回车。网址里的 `/hook` 不作为指令触发。
- 打卡、生活月历增加“每周选择几天”和“工作日”。工作日使用现有日期类型，放假暂停，补班正常；显示、实际打卡、提醒、月历实例展开使用同一规则，旧的每天、每隔 N 天、每周同一天保持兼容。安卓创建入口也支持选择每周几天。
- 根因：桌面 `record.set` 重建记录时遗漏 `sourceSessionId`，而旧版兜底只允许收获更新时间与结束专注相差五秒。补写或编辑收获会导致关联丢失，出现两行。现保留稳定来源 ID，原习惯收获与对应专注的正文编辑同步；历史无关联记录只有同日同习惯且唯一相同长正文才兜底合并，存在歧义不自动选择。删除操作与汇总、搜索、钩子共用相同关联逻辑。
- 夜读覆盖共享选择器（含展开菜单）、富文本笔记输入框、提示文字、钩子和滚动条；保留原 PDF 页面的显示。
- 整体计划在分页前稳定排序：待办/进行中 → 受阻 → 已完成。只改变界面展示顺序，不改动原始任务数据；跳转和引用继续使用原任务 ID。

原本的“习惯完成情况”和“专注计时”继续各自保存，合并的是同一次行动的关联与收获展示，不删除计时或完成数字。

实际历史数据已于本次修复恢复 2026-10-14、10-15、10-16 的三组关联，另补齐两条结束时间完全相同的旧空白收获关联（不改变原有显示）。修改前的原始 JSON 与精确变更清单只保存在本机 `outputs/backups/before-fixes-0.27.1`，不进入仓库。

验证包括规则与旧规则兼容、工作日覆盖、月历/记录/提醒一致性、补写与编辑后的关联保持、歧义防护、配对删除，以及真实 Electron 中中文/输入法钩子触发、重复方式选择、跨分页排序和夜读实际计算配色。手机做浏览器回归与 Android 构建，未连接真实安卓设备。

本次 122 项核心测试通过；桌面五处界面修复与原钩子功能回归通过，手机版新控件和既有局域网双向数据链路回归通过。
