# 下一轮体验优化设计

优先解决常用操作的步骤、信息可读性和保存反馈，保持现有页面与能力。以下是方案，未实现的内容不作为当前能力承诺。

## 本次已完成：固定作息

时间横排；时间、主题和星期安排正文均 16px。第一列默认 220px、最小 200px，兼容旧版列宽，保留拖动与横向滚动，滚动时表头与时间列保持固定。调整区严格限定在列内，开始与结束一起保存，可取消。每段可折叠安排，一键折叠/展开全部；折叠保留时间与主题，不移动到隐藏列表、不改变任务或完成状态。折叠偏好在本机持久化，隐藏仍可恢复。

验证：Electron 隔离数据下检查字体、时间横排、调整区边界、两端时间共同修改、折叠后展开保留正文、重新打开保持折叠、最小列宽、940px 窗口横向滚动及固定表头。

## 优先级 1：让常用操作少一步

1. 列表统一“查看 → 就地编辑 → 保存/取消”：默认展示完整可读标题和两行摘要；更多内容按需展开。操作区固定大小，常用操作直接展示，删除、移动和重复规则放入更多菜单。
2. 输入统一 Enter 提交、Shift+Enter 换行、Esc 取消。多字段调整共同提交，避免单独修改开始时间时被旧结束时间拦住。输入中不抢焦点、不覆盖草稿。
3. 删除后提供短暂“撤销”，保留可恢复记录；整体任务与表格事项联动关系需在撤销时一起还原，不能只恢复 UI。

## 优先级 2：今天只突出现在要做的事

首页首屏依次展示“正在进行”“现在可以做的一件事”“今天剩余”；已完成收起，仍可查看。固定作息当天内容可作为参考展示，不自动转换为任务或打卡，也不重复计算完成率。休息日突出“主动休息”，提醒和计划的暂停范围清楚可见。

## 优先级 3：保存和同步的状态可见

本机保存、云端同步和语雀发布分别说明。输入时显示“草稿已保留”，正式保存后显示“本机已保存”，随后云同步成功再显示“已同步”。离线显示待传数量；冲突提供双方正文比较，不让用户面对 JSON。实时同步沿用已有账号和增量接口，另行接入实时通知、操作后提交、断线补齐。

## 优先级 4：学习和回顾衔接

学习卡片直接提供“继续阅读/播放”，记住阅读位置或用户手动填写的视频时间点；摘录、想法和图片笔记就地编辑。回顾按习惯、专注、阅读、工作计划分区，先呈现完成内容与收获，再让用户选一个下周调整，不另加长表单。

## 验收原则

同一类操作在各页使用同一文字、尺寸和位置；常用操作最多一次点击进入；所有隐藏、折叠和休息动作都说明影响范围；大段内容不撑坏卡片；320px 手机与最小桌面窗口均无整页横向溢出；新布局不改变已有数据关系。
