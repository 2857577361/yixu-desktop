# 一序安卓第一版 · 0.1.1

## 安装和离线使用

将 `一序-安卓-0.1.1.apk` 发到安卓手机，打开并允许安装。当前为测试 APK，Android 7 及以上。系统通知首次在「我的 → 开启提醒」申请；通知的「打卡一次」写入本机数据库，重试不会再次记数。部分厂商需要另行允许后台运行，精确提醒和重启后的实际行为仍需真机验收。

四个入口：

- 今天：计时习惯、每日打卡、多提醒时间、最低版、每周次数/分钟、主动休息、今天的安排。
- 记录：按日期写日记、便笺、稍后学习；正文直接显示图片，支持相册添加和粘贴图片。安卓系统分享的网页文字可送到稍后学习，文章/视频使用系统浏览器打开。
- 计划：选中日的五类安排、横向本周表、整体任务次数、直接安排、累计完成、修改和删除；生活安排与周计划保持独立，支持每日、隔日、每周重复。
- 我的：本周专注和收获、休息统计、通知权限、同步状态、冲突选择、备份和导入。

桌面新版设置中有「导出手机备份」，输出 JSON，可在手机「我的 → 导入桌面备份」导入。导入前自动保存手机原数据。JSON 只包含记录及图片引用；跨设备传图片需要云同步。手机单独添加的图片会保存本机，不依赖云端。

## 云同步接入

Supabase 项目 `yixu` 已在新加坡区域创建，创建时查询费用每月 0 美元。同步表和私有图片桶已部署；真实数据库的操作去重、冲突、账号隔离与匿名拒绝测试通过，安全 Advisors 无问题。项目地址和 publishable 公钥已预置在客户端，用户不需要复制配置。

首次在电脑设置中注册一序同步账号，按邮件完成确认后登录，再在手机登录同一账号。个人真实记录尚未上传；完整的登录、双端同步和图片上传仍等待用户注册登录后验证。

1. 已在指定组织创建项目，项目控制台：https://supabase.com/dashboard。
2. 同步迁移已应用，邮箱登录已启用，需要按邮件完成确认。
3. 在电脑设置和手机「我的」登录同一邮箱账号，勾选同步本机记录；高级连接设置已预置，无需填写。
4. 首次电脑登录上传已有记录；手机登录拉取。手动同步和应用前台定期同步。输入记录时不执行手机定期同步。
5. 用隔离测试账号验证：手机新增 → 电脑拉取、电脑新增 → 手机拉取、离线两端打卡累计、日记冲突、图片与删除。通过后再启用个人真实数据。

公钥可以进入客户端，service_role/secret key 不可以。安卓会话使用 Android Keystore AES-GCM 加密，桌面会话使用 Electron safeStorage 与系统钥匙串。语雀 Token/Cookie 保留桌面，不上传 Supabase。

第一版服务端每条记录按账号隔离，客户端无直接写表权限，只能调用检查账号的事务 RPC；图片桶私有、按账号路径隔离、下载短期签名。打卡用唯一操作 ID 去重，其他记录带基准版本；冲突保留双方正文并等待本人选择。

文字、日记、便笺、习惯、打卡、专注会话、生活安排、五类周计划、休息日、学习记录参与同步。PDF 文件、阅读标注和阅读时长、固定作息表、游戏、语雀凭证不参与这一版云同步。设备撤销、后台任务同步、完整手机版阅读器后续补充。

## 开发

```sh
cd mobile
npm ci
npm run build
npm run android:apk
```

要求 Node 22、JDK 21、Android SDK 36。首次构建会下载 Gradle 与安卓依赖。SDK 路径写本机 `mobile/android/local.properties`，此文件不提交。调试 APK 为本机调试签名，换开发电脑前需保留签名以免后续覆盖安装失败；正式发布前建立稳定签名配置。
