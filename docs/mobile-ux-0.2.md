- 今天：今日完成与专注摘要、专注计时、习惯快捷操作、打卡加一次；提醒时间、撤销和删除收进更多操作。新增表单按需展开。
- 记录：日记独立书写区与保存状态；便笺和学习记录卡片。日记、便笺和学习表单的未提交草稿保存在本机，切换页面或重新打开可继续。
- 计划：当天五类分类按需展开，选择整体任务后自动显示安排的分类；完整周表保留横向滚动。完成绿色勾、跳过红色叉。
- 我的：回顾、提醒、同步、备份分区。已登录后不重复展示登录表单，连接错误用可读提示显示。
- 操作后局部更新，保留滚动位置、正在填写的表单、已展开区域和编辑器。关闭编辑区之前需保存；未提交的草稿只在本机。

`npm test`：63 项通过。`npm run test:mobile`：用隔离浏览器数据验证 320、360、390、430、768、1024px 和横屏四个页面无整页横向溢出；打卡保持同一 DOM 节点；日记自动保存；便笺草稿、编辑保留正文和多条独立保存；整体计划关联进度与修改；旧 ID 修复；安全边距与键盘布局。

桌面 Electron 隔离数据验证同步区勾选框 18px、登录按钮对齐与管理区间隔。安卓 Gradle 构建成功，桌面签名验证通过。未连接安卓真机，原生键盘、状态栏、图片选择和系统通知仍需在设备上验收。

## 安装

将新版 APK 发到已安装旧版的同一手机，直接覆盖安装，不要卸载旧版。当前 APK 使用本机原来的调试签名；换电脑构建或正式发布需要保持签名一致。桌面版安装到 `/Applications/一序.app`，本机记录在应用目录外保留。
